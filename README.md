# Variable Page Width

Drag note edges to set per-note page width, single-sided margins, and indents.

## Install manually

Copy `manifest.json`, `main.js`, and `styles.css` (if present) into `<vault>/.obsidian/plugins/variable-page-width/`, then enable the plugin in Obsidian.

## Develop

Run `npm install` and `npm run build` from this directory.
