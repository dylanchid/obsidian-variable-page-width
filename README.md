# Variable Page Width

Drag note edges to set per-note page width, single-sided margins, and indents.

## Use

Drag a Markdown note's page edges to adjust width and spacing. Run **Set page width for this note** for a precise value or **Reset page width, margins, and indents for this note** to clear its overrides. Settings control the default and allowed range, plus whether note-specific values are persisted in frontmatter.

## Install manually

Run `npm ci && npm run build`, then copy `manifest.json`, `main.js`, and `styles.css` into `<vault>/.obsidian/plugins/variable-page-width/`. Enable the plugin under **Settings → Community plugins**.

## Develop

Run `npm ci` and `npm run build` from this directory.
